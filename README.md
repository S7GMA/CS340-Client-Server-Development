# CS340-Client-Server-Development Portfolio Reflection

1. Writing Maintainable, Readable, and Adaptable Programs

In Project One, I created a Python CRUD module using an AnimalShelter class to perform Create, Read, Update, and Delete operations in MongoDB. Each operation has its own method, which keeps the database code organized and reusable. In Project Two, I used Python, MongoDB, and Dash to build a dashboard for Grazioso Salvare. The CRUD module's read() method allows the dashboard to retrieve animal records using database queries.

One advantage of separating the database operations from the dashboard is that the code is organized into different responsibilities. The CRUD module handles database operations, while the dashboard handles displaying and filtering information. This approach also gives me a module that I can adapt for other projects that need to create, retrieve, update, or delete database records.

2. Approaching Problems as a Computer Scientist

For the Grazioso Salvare project, I worked with MongoDB queries and Python to connect animal shelter data to an interactive dashboard. I implemented filtering options for different rescue categories, including water rescue, mountain or wilderness rescue, and disaster or individual tracking. The dashboard includes a data table, a pie chart showing breed distribution, and a map that displays animal locations.

This project required me to connect multiple components, including database queries, Python code, and dashboard widgets. I also worked with MongoDB data and handled the _id field, which uses ObjectId values. The project gave me experience working with database operations and using the retrieved information in different parts of a dashboard. For future projects, I can apply the same general approach of using reusable database methods and connecting retrieved data to an application interface.

3. What Computer Scientists Do and Why Their Work Matters

Computer scientists design the software, systems, and algorithms that make modern technology work. Day to day, that means building apps, designing databases, securing networks, training machine learning models, and solving problems efficiently at scale. Some work on practical products, while others do research that pushes what computers can do.

Their work matters because almost everything we rely on runs on it: banking, healthcare, communication, transportation, and education. A good computer scientist doesn’t just write code, they break big messy problems into clear, testable pieces and build solutions that are fast, secure, and maintainable. As a solo developer building apps like Velvet and Happier, I see this firsthand: the decisions you make about architecture and design directly shape how real people experience a product. That’s why the field matters. It turns ideas into tools that people use every day.
